# Quant Backtesting Engine

A Python-based quantitative trading research framework for testing systematic trading strategies on historical market data.

## Features
- SMA crossover strategies
- Performance analytics
- Sharpe ratio
- Drawdown analysis
- Trade logging
- Benchmark comparison
- Interactive visualizations

## Technologies
- Python
- pandas
- numpy
- matplotlib
- yfinance
